# Bill-Split
📌 Bill Split
A simple and intuitive app for splitting bills among friends and family 

# 🚀 Overview
Bill Split helps users easily divide expenses when dining out, ensuring everyone pays their fair share. Users can input the total bill, set a tip percentage, and split costs evenly or by specific amounts based on individual orders. The app then generates a message for the payer to send to contacts, notifying them of their dues.

# 🎯 Features
✅ Input total bill amount and tip percentage
✅ Split bills evenly or by custom amounts
✅ Generate and send payment requests via messaging
✅ User-friendly and intuitive UI

# 🛠 Tech Stack
Frontend: React Native, Expo
Backend: Node.js, Express
Database: MongoDB / Firebase
